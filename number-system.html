🔢 Lesson 4: Number Systems & Binary Arithmetic

Number Systems

Number systems are ways to represent quantities using a set of digits or symbols, defined by their base (or radix).

Binary (Base 2)

  • Digits: 0 and 1 (bits)
  • How it works: Foundation of all computer operations. Each position represents a power of 2.
  • Example: $1011_2$ = 11 in decimal.

Hexadecimal (Base 16)

  • Digits: 0-9 and A-F ($A=10$, $B=11$... $F=15$)
  • Example: $3A_{16}$ = 58 in decimal. Commonly used to represent memory addresses.

Binary Arithmetic

Binary Addition Rules

  1 0 1 0  (Decimal 10)
+ 1 1 0 1  (Decimal 13)
---------
1 0 1 1 1  (Decimal 23)

Binary Subtraction

  1 0 1 1  (Decimal 11)
- 0 1 1 0  (Decimal 6)
---------
  0 1 0 1  (Decimal 5)
