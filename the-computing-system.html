💻 Lesson 3: Computer System Overview

A computer system is an integrated set of components that work together to process data and perform tasks.

1. Hardware

Hardware refers to the physical parts of a computer that you can see and touch.

  • Input devices: keyboard, mouse.
  • Output devices: monitor, printer.
  • Storage devices: hard drives, SSDs.

2. Software

Software is the programs and instructions that tell the hardware what to do.

  • System software: Operating System (Windows, macOS).
  • Application software: MS Word, web browsers.
